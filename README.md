# car-financing-simulator-js

======================================================================
               HOW TO RUN THE FINANCING SIMULATOR
======================================================================
To run the code, you will need a web browser 
(e.g., Chrome, Firefox, Opera, Microsoft Edge, etc.).

Follow one of the methods below:

----------------------------------------------------------------------
METHOD 1: RUN DIRECTLY IN THE BROWSER
----------------------------------------------------------------------
1. Open 'src.js' and copy all the code.

2. Open your preferred web browser.

3. Right-click anywhere on the page and select "Inspect" or 
   "Inspect Element" depending on your browser.

4. In the side or bottom panel that opens, click the "Console" tab 
   or the square icon with a greater-than sign (>), depending on your browser.

5. Paste the copied code and press ENTER. The simulator will start 
   prompting you on the screen.

*NOTE: If a browser warning appears when trying to run the code, type 
'allow pasting' (or 'permitir colagem', depending on your browser language), 
paste the code, and press ENTER again to execute.

----------------------------------------------------------------------
METHOD 2: RUN ON PROGRAMIZ
----------------------------------------------------------------------
1. Open 'src.js' and copy all the code.

2. Go to: https://www.programiz.com/javascript/online-compiler/

3. Delete the default code displayed on the page.

4. Paste the 'src.js' code into the editor and click the "Run" button. 
   The simulator will start prompting you.

----------------------------------------------------------------------
INPUT AND OUTPUT EXAMPLE
----------------------------------------------------------------------
Input:
Enter the car price: $ 60000
Enter the down payment amount: $ 15000
Enter the number of installments (between 12 and 60): 48
Enter your state abbreviation (UF): CE
Enter your monthly income: $ 8000
Enter the monthly interest rate (% per month): 1.5

Output:

Car: $ 60000 | State: CE
1st Installment: $ 1612.50
Last Installment: $ 951.56
Year 1 Property Tax (IPVA): $ 1800.00
